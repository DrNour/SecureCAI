# SecureTerm Web

SecureTerm Web adds controlled URL collection to the SecureTerm workflow.

## Workflow

1. Enter a public webpage URL.
2. Fetch readable page text.
3. Review and edit the working corpus.
4. Match controlled English–Arabic terms.
5. Generate candidate Arabic renderings through the controlled termbase.
6. Validate, edit, reject, or escalate each aligned segment.
7. Export the alignment and source register.

## Safeguards

- Use public and permitted sources only.
- Respect terms of use, copyright, robots policies, and institutional rules.
- Do not collect classified, personal, restricted, or confidential pages.
- Preserve URL and retrieval time for traceability.
- Treat scraped text as a candidate source that requires human verification.
