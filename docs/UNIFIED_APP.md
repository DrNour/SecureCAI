# SecureTerm Pro unified app

This version extracts candidate multi-word phrases from the source itself rather than only matching a fixed glossary. It also identifies possible named entities, acronyms, numbers, and times.

Deploy with main file: secureterm_pro_app.py

The application supports URL collection, TXT/DOCX/PDF upload, controlled termbase editing, candidate Arabic equivalents, source-segment alignment, review statuses, and downloadable reports.
