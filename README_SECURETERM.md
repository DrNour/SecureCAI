# SecureTerm Pro

SecureTerm Pro is a research prototype for professional interpreters and translators working with high-stakes English–Arabic material.

It supports the work that happens before an assignment:

- briefing-document ingestion;
- controlled terminology management;
- extraction of numbers, times, acronyms, and possible named entities;
- terminology matching against a project termbase;
- preparation questions for unresolved items;
- downloadable termbases and briefing sheets.

The prototype does not claim to provide autonomous live interpreting. It makes preparation, terminology governance, and professional validation more systematic.

Run locally:

    pip install -r requirements.txt
    streamlit run secureterm_app.py

Use synthetic or institutionally approved non-sensitive material only.
